# 🎮 Jogo Dandara dos Palmares

Jogo educativo sobre **Dandara dos Palmares** e a história do Quilombo dos Palmares, desenvolvido por mim no início da graduação na UFRN, para a disciplina de **Lógica de Programação**, em JavaScript com a biblioteca **p5.js**.

▶️ **[Jogar online](https://editor.p5js.org/beatrizmorais02/full/aYySgsEPl)**

## Sobre o jogo

A própria Dandara conta a sua história: o Quilombo dos Palmares, a resistência contra a escravização e a luta ao lado de Zumbi. Entre os textos, o jogador passa por **duas fases**, com vidas, pontuação e níveis.

## Como jogar

- **Setas do teclado** (← → ↑ ↓): movimentam a personagem
- **Mouse**: navega pelos menus (*Jogar*, *Info*, *Créditos*)

## Tecnologias

JavaScript · p5.js · HTML · CSS
